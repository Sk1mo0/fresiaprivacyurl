Política de Privacidad de Fresia

Última actualización: 11 de septiembre de 2026

Fresia es una aplicación utilizada para administrar y publicar contenido en cuentas y páginas de redes sociales autorizadas por el usuario. Esta Política de Privacidad explica qué información puede procesar Fresia al utilizar las APIs y servicios de Meta, incluyendo Facebook e Instagram.

1. Información que procesamos

Fresia puede procesar la información necesaria para prestar sus funciones, incluyendo:

  • Identificadores de cuentas, páginas de Facebook y cuentas profesionales de Instagram.
  • Tokens de acceso y credenciales de autorización proporcionadas por Meta.
  • Información básica necesaria para identificar las páginas o cuentas administradas.
  • Contenido que el usuario decide publicar, como texto, imágenes, videos y datos relacionados con publicaciones.
  • Información técnica necesaria para realizar solicitudes a las APIs de Meta y verificar su resultado.

2. Cómo utilizamos la información

La información procesada por Fresia se utiliza únicamente para:

  • Conectar con las cuentas y páginas que el usuario haya autorizado.
  • Publicar, administrar o consultar contenido cuando el usuario lo solicite.
  • Permitir el funcionamiento de integraciones con Facebook e Instagram.
  • Mantener la seguridad y el funcionamiento técnico de la aplicación.

3. Uso de datos provenientes de Meta

Fresia utiliza las APIs oficiales de Meta únicamente dentro de los permisos concedidos por el usuario y conforme a las políticas aplicables de Meta. Fresia no utiliza los datos obtenidos mediante estas APIs para crear perfiles publicitarios ni para vender información personal.

4. Compartición de información

Fresia no vende información personal. La información puede ser transmitida a Meta cuando sea necesario para ejecutar una acción solicitada por el usuario, como publicar contenido en Facebook o Instagram. También podría procesarse mediante proveedores técnicos estrictamente necesarios para operar la aplicación, cuando corresponda.

5. Almacenamiento y seguridad

Fresia procura limitar el almacenamiento de información al mínimo necesario para operar sus funciones. Cuando se almacenan tokens de acceso u otra información de autenticación, deben protegerse mediante medidas técnicas razonables y utilizarse únicamente para las finalidades descritas en esta política.

6. Retención de datos

La información se conserva únicamente durante el tiempo necesario para proporcionar las funciones de Fresia o cumplir obligaciones técnicas o legales aplicables. Cuando deja de ser necesaria, puede ser eliminada o dejar de utilizarse.

7. Eliminación de datos

El usuario puede solicitar la eliminación de los datos asociados con Fresia enviando un correo a REEMPLAZA_CON_TU_CORREO. La solicitud deberá identificar suficientemente la cuenta relacionada para poder localizar y eliminar la información correspondiente.

El usuario también puede revocar el acceso concedido a Fresia desde la configuración de Facebook, Instagram o Meta correspondiente.

8. Servicios de terceros

Fresia puede interactuar con servicios proporcionados por Meta Platforms, Inc. El uso de Facebook e Instagram también está sujeto a las políticas, condiciones y configuraciones de privacidad de Meta.

9. Cambios a esta política

Esta Política de Privacidad puede actualizarse cuando cambien las funciones de Fresia, sus integraciones o los requisitos legales y técnicos aplicables. La fecha de la última actualización aparecerá al inicio de esta página.
